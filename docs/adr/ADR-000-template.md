# ADR-000 — Template

**Status:** Template (copy this file; never edit ADR-000 itself)

---

**Decision:** State the decision in one or two sentences, in the present tense,
as a thing that is now true. Not "we should" — "we do".

**Why:** The reasoning that would let a future agent re-derive this decision.
Include the constraint that actually forced it. If you cannot name a constraint,
you may not have a decision — you may have a preference.

**Rejected:** The alternatives that were seriously considered, each with the
reason it lost. This section is what stops the decision being re-litigated
every six months.

**Consequences:** What this costs, what it forecloses, and what maintenance it
creates. Be honest about the bad parts; an ADR that lists only benefits is
advocacy, not a record.

**Verification:** Any `[VERIFY]` this ADR depends on — the exact command, what a
pass looks like, and the fallback if it fails.

---

Numbering is sequential and permanent. An ADR is superseded, never deleted or
rewritten: add a new one and mark this header
`**Status:** Superseded by ADR-0NN`.

ADRs are settled law (PRD 0.1). An agent that believes an ADR is wrong escalates
per PRD 14.6; it does not decide differently on its own.
